Smart Civic Issue Reporting & Resolution System

A web-based civic issue reporting and resolution platform that allows citizens to report public issues, track their complaints, and helps government departments manage and resolve reported issues efficiently.

🚀 Features
👤 Citizen
Register and log in to the system
Report civic issues with relevant details
Select issue category and priority
Add location and issue description
Track submitted complaints
View complaint status and updates
🏢 Department
View complaints assigned to the department
Manage reported civic issues
Update complaint status
Handle issues based on category and priority
👨‍💼 Admin
Manage users and departments
Monitor reported complaints
View issue statistics and analytics
Track complaint resolution
Maintain an audit trail of important activities
🗺️ Location & Map
Location-based issue reporting
Interactive map integration
Display civic issue locations
Support for location-based civic issue management

⚙️ Installation & Setup
1. Clone the repository
git clone https://github.com/richa2193/smart-civic-web-app.git
2. Open the project
cd smart-civic-web-app
3. Create a virtual environment
python -m venv venv
4. Activate the virtual environment
Windows
venv\Scripts\activate
5. Install dependencies
pip install -r requirements.txt
6. Run database migrations
python manage.py migrate
7. Start the Django development server
python manage.py runserver

Then open:

http://127.0.0.1:8000/

🎯 Project Objective

The goal of this project is to provide a centralized platform for reporting and managing civic problems such as road damage, garbage, street-light issues, water leakage, drainage problems, traffic signals, illegal dumping, and other public infrastructure issues.

The system connects citizens with the appropriate departments and provides a structured way to monitor complaints from reporting through resolution.
